File structure:

    Header:
        Magic Number

    Body:
        Row Groups:
            - Column A:
                - Data
            - Column B:
                - Data
            ...
        ...
        
    Footer:
        - Schema info:
            - Total amount of records (4)
            - Max row group record amount (4)
            - Field amount (4)
            - Field metadata {name, age, ...}:
                - Column size (4)
                - Column name (20)
                - Column type (4)
                - Column number (4)

        - Row group metadata {0, 1, 2, ...}:
            - Column metadata {A, B, C, ...}:
                - Column offset (4)               
    Footer size (4)
    Magic Number
